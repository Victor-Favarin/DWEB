# Mercadinho Silva Camargo — Projeto Final DWEB

Projeto em HTML, CSS e JavaScript, desenvolvido a partir do login e cadastro de produtos originais.

## Executar
Abra `index.html` no navegador. Login de demonstração: **admin / 1234**.

## Funcionalidades
- Login de demonstração e dashboard com navegação.
- Cadastro, edição, exclusão e pesquisa de produtos (base original preservada).
- Cadastro, edição, exclusão e consulta de fornecedores.
- Consulta de estoque, alertas de estoque baixo e zero, entradas, saídas (inclusive clicando no produto) e ajustes.
- Relatório filtrável por produto, tipo e data, com impressão.

**Persistência:** `localStorage` do navegador, sem banco de dados. Dados não são sincronizados entre aparelhos ou navegadores; o login é somente demonstrativo, não seguro para produção.
